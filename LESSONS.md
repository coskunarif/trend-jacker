- **[Trigger]** Testing automatic async page-load actions in E2E tests **[Symptom]** CPU load spikes in parallel runners cause race conditions on network assertion counts **[Remediation]** Explicitly await page.waitForResponse before verifying network counts.
- **[Trigger]** Asserting visibility during viewport resizes or layout transitions in Playwright **[Symptom]** Arbitrary timeouts fail under heavy CPU load **[Remediation]** Wrap assertions in expect(async () => { ... }).toPass() to poll/retry assertions automatically.
- **[Trigger]** Running concurrent SQLite writes in parallel Playwright E2E tests **[Symptom]** Tests fail with transient 'database is locked' errors **[Remediation]** Force a single runner worker (--workers=1) or enable WAL mode on the shared SQLite database.
- **[Trigger]** Enforcing JSON structures with Gemini API in Node.js **[Symptom]** Output shape variations trigger parsing and runtime errors **[Remediation]** Specify responseSchema inside generationConfig to guarantee type-safe structured JSON output.
- **[Trigger]** Validating Schema.org JSON-LD structure in E2E tests **[Symptom]** Simple text matching fails to verify nested fields and relationships **[Remediation]** Extract script tag content, parse as JSON, and assert nested properties directly.
- **[Trigger]** Verifying dimensions of canvas-generated images in E2E tests **[Symptom]** Importing heavy image processing libraries increases test bundle size and execution latency **[Remediation]** Parse raw PNG header buffer bytes directly (width at bytes 16-20, height at 20-24) to validate size.
- **[Trigger]** Verifying outbound intent sharing links in Playwright **[Symptom]** Timing races between button clicks and page opens cause target page capture failures **[Remediation]** Use context.waitForEvent('page') to capture the target page and verify query params directly.
- **[Trigger]** Verifying external outbound intent URLs (e.g. Twitter, Pinterest) in E2E tests **[Symptom]** High runner load causes timeouts when awaiting full page load states on external platforms **[Remediation]** Assert target URL query parameter construction immediately upon popup capture without waiting for full load.
- **[Trigger]** Accessing shared SQLite DBs from test assertions and backend code concurrently **[Symptom]** Unclosed read connections lock the database and block writes **[Remediation]** Always close DB connections before triggering outbound API/network requests.
- **[Trigger]** Overlaying dynamic text on an HTML5 canvas **[Symptom]** Long strings overflow canvas layout bounds **[Remediation]** Implement font-size reduction loops to dynamically fit text within boundary constraints.
- **[Trigger]** Querying caches with mixed-case strings **[Symptom]** Casing mismatches bypass the cache, causing redundant generation costs **[Remediation]** Normalize lookup keys to lowercase at database boundaries.
- **[Trigger]** Testing clipboard copy in headless Playwright **[Symptom]** Security access denials prevent reading/writing to the clipboard **[Remediation]** Explicitly grant 'clipboard-read' and 'clipboard-write' permissions to the browser context.
- **[Trigger]** Updating complex UI views atomically in response to clicks **[Symptom]** Awaiting async API calls mid-render yields the event loop, causing E2E test race conditions **[Remediation]** Fire async API checks as un-awaited background promises during the synchronous rendering pass.
- **[Trigger]** Direct SQLite connections opened in E2E tests **[Symptom]** Missing busy timeouts cause transient database lockouts **[Remediation]** Match backend configs by setting WAL mode and PRAGMA busy_timeout = 5000.
- **[Trigger]** Executing concurrent writes under SQLite deferred transactions **[Symptom]** Concurrent read-to-write upgrades deadlock the database **[Remediation]** Start write transactions with BEGIN IMMEDIATE TRANSACTION to lock the database early.
- **[Trigger]** Asserting viewport visibility of animated layout containers **[Symptom]** Strict inclusion assertions fail on smaller screen heights **[Remediation]** Check for partial intersection (top < viewport height, bottom > 0) instead of full inclusion.
- **[Trigger]** Asserting negated class names using regex in Playwright **[Symptom]** Negating /locked/ matches overlapping names like 'unlocked', triggering false failures **[Remediation]** Use strict boundary anchors in regex assertions to prevent partial class matches.
- **[Trigger]** Defining explicit route redirects with Fastify static plugin registered **[Symptom]** Wildcard static file delivery bypasses route handlers **[Remediation]** Register explicit path redirects before registering wildcard static plugins.
- **[Trigger]** Identifying client protocol behind reverse proxies (like Cloud Run) **[Symptom]** Redirection loops or incorrect canonical hostnames **[Remediation]** Validate both the x-forwarded-proto header and the raw.encrypted property.

- **[Trigger]** Embedding JSON data inside inline script tags for client-side hydration **[Symptom]** Raw HTML tag characters in the JSON can break script boundaries and introduce XSS vulnerabilities **[Remediation]** Safe-escape '<' and '>' characters in the JSON string as unicode sequences (\\u003c and \\u003e).
