# Specification: Social Media Previews & Search Engine Indexing Coverage

## Objective
Ensure correct display of social media preview images (convert OpenGraph SVG previews to rasterized PNGs) and maximize organic click-through rate and search ranking visibility by expanding search engine indexing coverage (including localized trend page URLs).

---

## Acceptance Criteria

### `[AC-1]` Dynamic OG PNG Preview Cards
- **Description**: The OpenGraph endpoints (`/api/og/:slug` and `/api/og/:slug/:lang`) must serve a rasterized PNG image instead of raw SVG XML content.
- **Verification Method**:
  1. Send a HTTP `GET` request to `/api/og/google-gemini` and `/api/og/google-gemini/es`.
  2. Verify the HTTP status is `200`.
  3. Verify the `Content-Type` response header is exactly `image/png`.
  4. Parse the response binary buffer to verify it is a valid PNG and check its dimensions. The dimensions must be exactly **1200x630** pixels.
     - *Helper logic for dimension check via bytes*:
       - Width (big-endian 32-bit int) is at offset 16 (bytes 16–19). Must equal `1200`.
       - Height (big-endian 32-bit int) is at offset 20 (bytes 20–23). Must equal `630`.

### `[AC-2]` Case-Insensitive Cache Lookup & Storage
- **Description**: The server-side cache for rasterized OG images must normalize lookup keys to lowercase to avoid redundant rendering/conversion costs.
- **Verification Method**:
  1. Call `/api/og/Google-Gemini` and `/api/og/GOOGLE-GEMINI` successively.
  2. Ensure the response returns the same cached PNG binary data.
  3. The internal cache key format must be `slug:lang` (both normalized to lowercase, e.g., `google-gemini:en` or `google-gemini:es`).

### `[AC-3]` Thematic Dynamic Category Styling
- **Description**: Both `/api/og` and `/api/topic-image` endpoints must dynamically render elements (vibe badge text, background color/gradients, and emoji) matching the trend's resolved category (Tech, Workplace, Innovation, Trending/Default) based on trend title keywords, rather than using a hardcoded placeholder.
- **Verification Method**:
  1. Call `/api/topic-image/google-gemini` (matches Tech keyword `google`). Assert that the returned SVG contains the text "Cutting Edge" and uses the Tech theme elements.
  2. Call `/api/topic-image/remote-job` (matches Workplace keyword `job`). Assert that the returned SVG contains the text "Future of Work".
  3. Call `/api/topic-image/solar-energy` (matches Innovation keyword `solar`). Assert that the returned SVG contains the text "Green Tech".
  4. Call `/api/topic-image/arbitrary-unknown-slug`. Assert that the returned SVG contains the text "Hot Vibe" (Default).
  5. Confirm that the same thematic parameters are applied to the PNG previews generated by `/api/og` endpoints.

### `[AC-4]` Multi-Language Search Engine Indexing
- **Description**: When newly discovered trends are cached, the search engine indexing notifier must construct and ping both the default English URL and the localized URL variants (`/es`, `/fr`, `/ja`) to IndexNow, ensuring global search visibility.
- **Verification Method**:
  1. Trigger a discovery of a new trend (e.g. `openai-gpt`).
  2. Assert that the list of URLs dispatched to IndexNow contains:
     - `https://viraljacker.com/t/openai-gpt`
     - `https://viraljacker.com/t/openai-gpt/es`
     - `https://viraljacker.com/t/openai-gpt/fr`
     - `https://viraljacker.com/t/openai-gpt/ja`
  3. In the testing environment, verify that all 4 variant URLs are generated and formatted correctly.

---

## Out of Scope
- establishing a public forecast dashboard for trend predictions (the runner-up task).
- converting browser-side canvas download mechanisms to use server-side generation.
- modifying existing client-side sessionStorage chat caching logic.

---

## Slices

### `[S-1]` Install Image Processing Dependency (`sharp`)
- **Focus**: Add `sharp` to the project dependencies to enable fast SVG-to-PNG rasterization on the server.
- **Files**:
  - `package.json`
- **ACs**: None (pre-requisite dependency)

### `[S-2]` Implement Server-Side Trend Category Resolver & Dynamic SVG Rendering
- **Focus**: Mirror the client-side `getTrendCategoryMeta` logic on the server to dynamically categorize trends. Update `/api/topic-image/:slug` and the SVG generation logic in `serveOgImage` to use these resolved colors, emojis, and vibe badges.
- **Files**:
  - `server.js`
- **ACs**: `[AC-3]`

### `[S-3]` Serve Rasterized PNG Previews and Implement In-Memory Caching
- **Focus**: Convert generated SVG code to PNG buffers via `sharp` inside the `/api/og` route handler. Set the `Content-Type` header to `image/png` and cache the generated PNG buffers in-memory using lowercase `slug:lang` keys.
- **Files**:
  - `server.js`
- **ACs**: `[AC-1]`, `[AC-2]`

### `[S-4]` Expand IndexNow Pings to Localized Trend URLs
- **Focus**: Modify the indexing notifier in `indexing.js` to format and submit all locale-specific variants of the trend pages.
- **Files**:
  - `indexing.js`
- **ACs**: `[AC-4]`
