# SPEC.md: Optimize Search Query Alignment and URL Readability

## Acceptance Criteria

- **[AC-1] Eliminate Hard-coded Character Truncation on Reddit Trend Titles**
  - **Description**: The hard-coded 60-character truncation logic (`title.substring(0, 60) + '...'`) in the Reddit RSS feed parser must be removed. The full thread title must be used.
  - **Verification**: Ingest or mock a Reddit RSS item with a title longer than 60 characters (e.g. 100 characters). The stored trend title must match the full, untruncated text exactly.

- **[AC-2] Full & Search-friendly Slug Generation for Trend URLs**
  - **Description**: Slugs generated by `titleToSlug` for long Reddit trends must map cleanly to the full, untruncated title. Slugs must not contain trailing `...` or cut-off words, providing descriptive search-intent-focused URLs.
  - **Verification**: Verify that `titleToSlug("World Cup tourists: what's your honest feedback on the USA's stadiums")` generates `world-cup-tourists-whats-your-honest-feedback-on-the-usas-stadiums`. Accessing this route in the dev server must render the details view with status `200`.

- **[AC-3] Dynamic Sitemap and Indexing API Synchronization**
  - **Description**: Dynamic sitemap (`sitemap.xml`) generation and search engine pings via Google Indexing API & IndexNow must utilize the untruncated slugs generated from the full trend titles.
  - **Verification**: Retrieve `/sitemap.xml` after a long Reddit trend is cached. The URL in `<loc>` tags must use the untruncated, search-friendly slug. The indexing ping script must successfully process and format all 4 localized variants using the untruncated slug.

- **[AC-4] UI Layout and Responsive Presentation of Long Titles**
  - **Description**: The UI layout must remain visually unbroken when displaying long trend titles. Long titles in both the sidebar/trend list and the detail page header must wrap naturally using CSS properties (`word-wrap: break-word` and `overflow-wrap: break-word`), ensuring no horizontal overflow or text overlap on mobile (375x667) and desktop (1280x800) viewports.
  - **Verification**: Playwright responsive viewport check ensures no horizontal scrolling (`window.innerWidth >= document.documentElement.scrollWidth`).

---

## Performance KPIs

- **[KPI-1] Feed Ingestion Latency**: Parsing and deduplicating Google & Reddit RSS feeds must complete in `< 500ms`.
- **[KPI-2] Pre-Rendered Page Load Latency**: Serving pre-rendered detail views `/t/:slug` from cache must complete in `< 50ms`.

## Interface Contract

- **`titleToSlug(title)` Function** (inside `server.js` / line 37):
  - Signature: `function titleToSlug(title: string): string`
  - Input: Full untruncated trend name or post title.
  - Output: URL-safe, clean slug.
- **`latestTrends` Array** (inside `server.js`):
  - Type: `Array<TrendItem>`
  - Field: `title` in each `TrendItem` must represent the full, untruncated trend title.

## Objections and Resolutions

- **Objection 1 (UI Layout Breakage)**: Displaying extremely long Reddit thread titles in the UI sidebar list could cause clutter or horizontal overflow.
  - **Resolution**: Verified that `.trend-item-title` and `.trend-title` classes in `public/styles.css` already support natural word wrapping. The sidebar layout wraps text cleanly, preventing any overflow.
- **Objection 2 (Database Column Size)**: Longer titles might exceed column sizing or index efficiency in SQLite.
  - **Resolution**: SQLite `TEXT` keys scale efficiently without performance penalties for strings under several kilobytes.
